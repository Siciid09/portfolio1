Unit 2: Oracle SQL Basics

DDL vs DML and Complete Practical Steps

What is SQL?

SQL is used to: Create database objects, Insert and manage data, and Modify structures. Oracle uses data types like NUMBER and VARCHAR2.

DDL (Data Definition)

  • CREATE Build new objects.
  • ALTER Change structure.
  • DROP Delete permanently.
  • RENAME Change table name.

DML (Data Manipulation)

  • INSERT Add new records.
  • UPDATE Modify existing records.
  • DELETE Remove data permanently.
  • SELECT Retrieve data.
Lab 1: CREATE TABLE (DDL)

PRIMARY KEY = Unique. NOT NULL = Mandatory.

CREATE TABLE Student (
    StID NUMBER(5) PRIMARY KEY,
    StName VARCHAR2(50) NOT NULL,
    StAdd VARCHAR2(100),
    StAge NUMBER(3)
);
Lab 2: INSERT Command (DML)
-- Method 1: Insert into all columns
INSERT INTO Student VALUES (101, 'Alice Johnson', '123 Maple St', 20);
-- Method 2: Insert into selected columns
INSERT INTO Student (StID, StName) VALUES (102, 'Bob Smith');
Lab 3 & 4: UPDATE & DELETE (DML)
UPDATE Student SET StAdd = '456 Oak Lane' WHERE StID = 102;
DELETE FROM Student WHERE StID = 101;
Lab 5: ALTER, RENAME, DROP (DDL)
ALTER TABLE Student ADD (PhoneNumber VARCHAR2(20));
RENAME Student TO University_Students;
DROP TABLE Student;

Unit 3: Data Retrieval & Filtering

Querying, Filtering, Sorting, and Pattern Matching

Lab 1 & 2: SELECT & DISTINCT

SELECT * FROM Student;
SELECT DISTINCT StAge FROM Student;

Lab 3: WHERE Clause

Operators: =, >, <, >=, <=, <>

SELECT * FROM Student WHERE StAge > 20;

Lab 4 & 5: ORDER BY & Logicals

SELECT * FROM Student ORDER BY StAge DESC;
SELECT * FROM Student WHERE StAge > 18 AND StAge < 25;

Lab 6 & 7: LIKE & BETWEEN

SELECT * FROM Student WHERE StName LIKE 'A%';
SELECT * FROM Student WHERE StAge BETWEEN 18 AND 25;

Unit 4: Functions & Joins

Single-Row, Aggregate Grouping, and Relationships

Lab 1: Single-row Functions

Operate on each row individually.

SELECT UPPER(EMPNAME) FROM EMPLOYEES;
SELECT LOWER(EMPNAME) FROM EMPLOYEES;
SELECT LENGTH(EMPNAME) FROM EMPLOYEES;

Lab 2: Group Functions

Aggregate rows to return a single result.

SELECT COUNT(*) FROM EMPLOYEES;
SELECT SUM(STAGE) FROM EMPLOYEES;
SELECT MAX(STAGE) FROM EMPLOYEES;

Lab 3 & 4: SQL Joins

INNER JOIN (Matching Only)

SELECT E.EMPNAME, D.DEPTNAME 
FROM EMPLOYEES E INNER JOIN DEPARTMENTS D
ON E.DEPTID = D.DEPTID;

LEFT JOIN (All Left + Matches)

SELECT E.EMPNAME, D.DEPTNAME 
FROM EMPLOYEES E LEFT JOIN DEPARTMENTS D
ON E.DEPTID = D.DEPTID;

FULL JOIN (All Records)

SELECT E.EMPNAME, D.DEPTNAME 
FROM EMPLOYEES E FULL JOIN DEPARTMENTS D
ON E.DEPTID = D.DEPTID;
